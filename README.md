## 📌 Project Overview

This project focuses on cleaning and preparing a raw dataset to make it ready for analysis. Real-world datasets are messy — they contain missing values, duplicate records, and incorrect formats. The goal of this project is to identify and fix all such issues so the data becomes accurate, consistent, and analysis-ready.

---

## 🎯 Goal

Clean a raw dataset by handling missing values, duplicates, and incorrect data.

---

## ✅ Key Requirements

- Identify missing or null values
- Remove duplicate records
- Correct data formats (dates, numbers, text)

## 🔍 Steps Performed

### Step 1 — Identify Missing / Null Values
- Scanned all columns for empty or null cells
- Filled missing values with appropriate defaults or removed incomplete rows

### Step 2 — Remove Duplicates
- Identified duplicate rows in the dataset
- Removed all duplicate entries to ensure each record is unique

### Step 3 — Correct Data Formats
- Fixed date columns to a standard format (YYYY-MM-DD)
- Corrected number columns (removed extra spaces, symbols)
- Standardized text columns (consistent capitalization)
